## Stack

## Users
Grant funders freeze observable acceptance criteria and escrow a fixed budget. Recipients submit public evidence for a milestone. Reviewers inspect actual execution without connecting a wallet.

## Product Purpose
Grant money that follows shipped work, not promises. Independently fetched evidence and semantic validator agreement authorize a deterministic fixed allocation.

## Operating Context
Up to three milestones, one to five criteria each. Validate the specification before funding. Claim before deadline; hold permits one resubmission. Native protocol appeals precede final settlement. StudioNet GEN is simulated development value.

## Capabilities and Constraints
Allowlisted GitHub release/tag at commit SHA, GitHub file at commit SHA, npm version, exact archive.org id_ snapshot with CDX verification, StudioNet explorer contract. Never manufacture finalized demo proof. Do not modify sibling projects or submit to the Portal.

## Brand Commitments
Original ledger / grant-agreement interface, restrained colour, clear typography, clause-like milestones, mobile-first. The user delegated implementation decisions through the build brief; no extra design approval round is needed.

## Evidence on Hand
